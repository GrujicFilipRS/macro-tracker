# Macro Tracker

Macro Tracker je veb aplikacija koja omogućava korisniku da postavi željenu količinu makroa (proteina, masti, ugljenih hidrata), i da na dnevnom nivou unosi koliko ih je pojeo tokom dana.

Aplikacija računa koliko još makroa korisnik mora da unese danas, a i takođe čuva sve prošle makroe koje je korisnik uneo prethodnih dana
